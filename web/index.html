the pipeline

How one photograph becomes a bill

  1. Classify. An ImageNet-pretrained CNN, run through ONNX Runtime on the photograph and its mirror image, sorts each region into seven road conditions. measured
  2. Segment. A pixel classifier trained on 4,720 hand-drawn polygons produces a defect mask — the defect's own footprint, not a rectangle around it. measured
  3. Project. Each mask pixel contributes the ground area of its own footprint, using that vehicle's camera calibration. Without a calibrated profile this is an estimate and says so. depends on calibration
  4. Estimate depth. A single photograph carries no depth information. We return an interval with its basis, never a point value dressed as a measurement. estimate
  5. Cost. MoRTH Section 500 tonnage. Cost is linear in area and depth, so the depth interval becomes a cost range. range
  6. Seal. SHA-256 over the order fields. Change a rupee and the seal breaks. verified by tests
