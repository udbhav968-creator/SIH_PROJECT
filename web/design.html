Capacity

change the assumptions — the estimate recalculates

Planning estimate, not a measurement. Measured inputs: 8 m is the implemented sampling default; ~2 s per frame is the measured single-core pipeline time. The two filters — the edge classifier and the repeat-sighting check — are what keep the server small.

Reliability, security, privacy

graceful degradation · implemented
  • no segmenter → box area, labelled as such
  • no IMU window → fusion reports unavailable
  • deep model fails to load → its classical fallback
  • no GPS → work order HELD_NO_GPS
  • no map key → OpenStreetMap, or an explicit UNAVAILABLE
controls
  • SHA-256 work-order seal, re-verifiable by anyone · implemented
  • recycled repair photos rejected · implemented
  • API key on write endpoints, constant-time compare · implemented (opt-in)
  • people and plates blurred · implemented (recall not measured)
  • TLS, device certificates, 7-day raw-frame retention (DPDP Act) · designed
