Responsible AI

mapped onto Microsoft's six principles — what exists, and what is missing
principlewhat the system doesgap
FairnessNo decision about any person; no demographic inference. The real risk is geographic: roads without buses go uninspected, and a model from one country fails in another — measured here as 33% on Indian roads before Indian data, 92.3% after.no per-city evaluation; non-bus roads need another source
Reliability & safetyHeld-out splits by photograph; models chosen on validation before the test set; classical fallback for every deep model; missing inputs are a 400, never a default; 200+ automated tests.no field validation of depth, PCI, deterioration; no bus footage yet
Privacy & securityPeople and plates blurred before sharing; no identity stored; sealed work orders; optional API key on write endpoints; static files from an allow-list only.blur recall unmeasured; on-bus blur, TLS, device certificates designed
InclusivenessRuns on an ordinary CPU; any camera via a calibration profile; the site works on a phone and without map tiles.English-only interface
TransparencyEvery number labelled measured / estimate / range; model cards with the weak classes; whole-frame classifier opinion shown beside the measured result; OpenAPI contract; withdrawn claims listed.—
AccountabilityEach served model identified by SHA-256 and the rule that chose it; each work order traceable to its sightings; a human authority issues repairs — the system recommends, it does not dispatch.no formal governance process with an authority yet
