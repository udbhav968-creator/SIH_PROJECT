three detectors, kept separate on purpose

Each training set labels only its own classes. A single merged model would learn that every unlabelled pothole in a crosswalk photograph is background, so each detector is trained, versioned and rolled back on its own.

Per-class thresholds come from each model card: the confidence that maximised F1 on the validation split. Scene facts, such as a pedestrian on a crossing, are geometric rules over the boxes, and each one names its rule.
